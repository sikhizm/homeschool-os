# Homeschool OS

A parent-guided family learning platform combining CBSE alignment, globally informed learning pathways, mastery-based progression, and age-appropriate play.

## Educational direction
- English-first instruction, with Punjabi and Hindi support
- 60 minutes of shared parent-guided learning per day
- Sikh heritage integrated naturally into learning
- Individual learning pathways and privacy-first child records

## Development phases
1. Foundation: Next.js, TypeScript, responsive dashboard
2. Private family profiles and authentication
3. Curriculum and competency maps
4. Annual, weekly, and daily planning
5. Lessons, activities, and printable resources
6. Baseline assessments, observations, and portfolios
7. Parent-reviewed AI assistance
8. Progress reporting

## Privacy
Do not commit children's personal information, assessment results, credentials, or photographs to this repository. Require authentication and appropriate data access controls before storing learner records.
