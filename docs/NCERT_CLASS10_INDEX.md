# NCERT Class 10 catalogue index

**Phase 7 audit date:** 2026-11-13  
**Scope:** a conservative, official-source-backed English-medium audit set.
The catalogue does not claim comprehensive Class 10 coverage.

## Direct-PDF policy

All 60 indexed slots have official Contents titles. Phase 7 verified no direct
Class 10 chapter PDF one by one, so the app presents an official NCERT book-portal
fallback for every Class 10 chapter. This is deliberate: a filename pattern, search
snippet, or generic portal range is not direct-PDF proof.

## Non-expansion commitments

- No QR-only extended learning, appendices, answer material, poems or component
  readings were silently converted into ordinary chapter records.
- No Class 10 chapter is auto-mapped to an NCERT outcome or an original skill.
- The three stable existing session IDs are reused for each verified chapter; no
  learner progress or historical session ID is migrated or regenerated.
- Official material remains external and copyrighted. Homeschool OS stores only
  source metadata, titles and original parent guidance.
