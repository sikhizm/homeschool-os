## Documented discrepancies

1. The PDF text layer of बांसुरी ch17 renders the title as "सूजन"; the parallel English text (Bansuri ch17 "Let's Create") and the chapter's create-a-scene content confirm the intended word is "सृजन" (creation). Recorded as "आइए, सृजन करें".
2. CIET Class 3 pages list chapters only as generic "Chapter-N" entries — unlike Class 1/2 they carry no titles, so contents came from the official prelims Contents pages instead.
3. The Santoor chapter-1 PDF opens with the unit material "Fun with Friends" before the "Colours" lesson content; the link is NCERT's official location for chapter 1.
